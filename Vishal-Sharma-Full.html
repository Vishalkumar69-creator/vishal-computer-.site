Chapter 1: Networking Kya Hai?

2 ya usse zyada computer ko jodna taaki data share ho sake. Jaise ghar me mobile-laptop ek WiFi se jude hai. Office me 1 printer 10 PC use karte hai wo networking hai.

Real Example Moranhat: Tumhari shop me 3 PC aur 1 printer hai. Bina network ke pen-drive se file deni padegi. Network se 1 click me share.

Chapter 2: Network Ke Prakar

PAN: 10m tak - Bluetooth
LAN: Ek building - School lab, Cyber cafe, Speed tez
MAN: Ek city - Moranhat se Dibrugarh tak cable
WAN: Pure duniya - Internet sabse bada WAN

Chapter 3: OSI Model - 7 Layers (Interview Question)

Trick: A P S T N D P - All People Seem To Need Data Processing

  • 7 Application - Browser, WhatsApp user dekhta hai
  • 6 Presentation - Encryption, format
  • 5 Session - Connection banata hai
  • 4 Transport - TCP/UDP - Data sahi pahucha ki nahi
  • 3 Network - IP Address - Rasta decide
  • 2 Data Link - MAC Address - Switch yaha kaam
  • 1 Physical - Cable, WiFi signal

Chapter 4: TCP/IP Model - Asli Internet Model

Application -> Transport (TCP/UDP) -> Internet (IP) -> Network Access

TCP vs UDP: TCP = Confirm delivery (WhatsApp), UDP = Fast, no confirm (YouTube Live, Gaming)

Chapter 5: IP Address Full

Example: 192.168.1.10 - 4 number 0-255 tak

Private IP: 192.168.x.x (ghar ke andar)
Public IP: Jio/Airtel deta hai internet par

Class A: 1-126 (Badi company)
Class B: 128-191 (Medium)
Class C: 192-223 (Hum use karte hai)

Chapter 6: Subnetting (Job ke liye sabse important)

Bade network ko chhote tukdo me baantna. Jaise 100 room hotel ko 10-10 room ke floor me.

192.168.1.0/24 = 254 device connect
/24 = 255.255.255.0 = 254 Hosts
/30 = 2 Hosts (2 router jodne ke liye)

Chapter 7: DNS, DHCP, NAT

DNS: google.com ko 142.250.190.14 me badalta hai - Internet ki phonebook
DHCP: Router auto IP deta hai, manual likhne ki zarurat nahi
NAT: 1 Public IP se 5 mobile chalana

Chapter 8: Devices - Router, Switch, Hub

  • Router: Alag network jodta hai, Internet laata hai
  • Switch: Same network me PC jodta hai, 24 port office me
  • Hub: Purana, ab nahi use
  • Access Point: WiFi range badhata hai
  • Modem: Fiber light ko internet banata hai
